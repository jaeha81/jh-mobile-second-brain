# Agent Registry

## Claude Code
- **역할**: 메인 구현 및 설계 담당
- **담당 영역**: 전체 파일 생성, 아키텍처 결정, 코드 구현
- **진입점**: 이 llm-wiki 폴더 + handoff-prompt.md 읽고 시작

## Codex
- **역할**: 검증, 리뷰, 누락 점검, 오류 탐지
- **담당 영역**: 보안 취약점, 타입 오류, 로직 버그, 누락 파일
- **진입점**: `docs/codex-validation-checklist.md` 체크리스트 기준으로 검증

## LLM Wiki
- **역할**: 장기 기억, 상태 저장, 다음 세션 인계
- **담당 영역**: `llm-wiki/` 폴더 전체 관리
- **업데이트 시점**: 기능 완료 시, 세션 종료 전

## 사용자 (재하)
- **역할**: 최종 결정권, 승인 게이트, 운영
- **담당 영역**: 환경변수 설정, GitHub repo 준비, 배포 결정
- **원칙**: 승인 없이 실코드 생성 금지

## 역할 간 연결
```
재하 (승인) → Claude Code (구현) → Codex (검증) → LLM Wiki (기록) → 재하 (확인)
```
