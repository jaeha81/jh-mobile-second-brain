# Future Roadmap

MVP 이후 후순위 확장 항목. 현재 구현하지 않음.

## Phase 2 — AI 처리

| 항목 | 설명 |
|------|------|
| STT 음성 텍스트 변환 | Whisper API로 webm → 텍스트 변환 후 일일 기록에 포함 |
| GPT 자동 요약 | 일일 이벤트 + 메모를 GPT로 요약해 `## 1. 요약` 자동 채우기 |
| 자동 태그 생성 | 메모 내용 분석해서 Obsidian 태그 자동 제안 |
| 프로젝트 자동 분류 | 반복 키워드 기반으로 노트를 프로젝트 폴더에 자동 이동 제안 |
| Obsidian 내부 링크 자동 생성 | 기존 Vault 노트와 연결되는 `[[링크]]` 자동 삽입 |

## Phase 3 — 자동화

| 항목 | 설명 |
|------|------|
| GitHub Actions 일일 자동 정리 | 매일 자정 raw-data를 처리해서 Vault에 요약 노트 자동 생성 |
| 자동 동기화 interval | 설정한 주기마다 백그라운드 동기화 (Service Worker) |
| 오프라인 우선 동기화 고도화 | 오프라인 중 쌓인 데이터 온라인 복귀 시 자동 배치 처리 |

## Phase 4 — 인프라 확장

| 항목 | 설명 |
|------|------|
| FastAPI 백엔드 분리 | Next.js API Route → 독립 FastAPI 서버로 분리 |
| Supabase 백업 | GitHub 외 Supabase를 보조 저장소로 사용 |
| 관리자 대시보드 | 전체 활동 통계, 태그 분석, 트렌드 시각화 |
| LLM Wiki 자동 업데이트 | 세션 종료 시 llm-wiki/current-state.md 자동 갱신 |

## Phase 5 — 플랫폼 확장

| 항목 | 설명 |
|------|------|
| 모바일 위젯 | 홈 화면 위젯에서 바로 메모 입력 |
| 음성 명령 기반 기록 제어 | "기록 시작", "메모: ..." 음성 명령 |
| 프로젝트별 세컨드 브레인 분리 | 프로젝트 컨텍스트별로 별도 Vault 구조 |
| 다중 기기 동기화 | 여러 기기의 IndexedDB를 GitHub 기준으로 동기화 |

## 절대 구현하지 않는 것

- 다른 앱 화면 감시
- 통화 녹음
- 백그라운드 상시 녹음
- 키로깅
- 비밀번호·민감정보 자동 수집
- 사용자 동의 없는 수집
