# 개인정보 보호 안내 (초안)

최종 수정: 2026-04-25

## 이 앱이 수집하는 것

| 항목 | 수집 여부 | 조건 |
|------|-----------|------|
| 웹앱 내부 버튼 클릭 | ✅ | 사용자 동의 + 기록 시작 후 |
| 페이지 이동 | ✅ | 사용자 동의 + 기록 시작 후 |
| 빠른 메모 텍스트 | ✅ | 사용자가 직접 입력한 경우 |
| 음성 녹음 | ✅ | 사용자가 녹음 버튼을 직접 누른 경우만 |
| 기기 유형 (mobile/desktop) | ✅ | 최소 정보만 |

## 이 앱이 수집하지 않는 것

- 다른 앱 화면 및 활동
- 카카오톡, 문자, 이메일 내용
- 전화 통화
- 외부 브라우저 방문 기록
- 비밀번호, 인증번호, 토큰, API 키
- input[type=password] 입력값
- 백그라운드 상시 녹음
- 위치 정보
- 연락처, 사진, 캘린더

## 데이터 저장 위치

1. **기기 로컬** (IndexedDB) — 기본 저장소
2. **GitHub private repo** — 사용자가 동기화 버튼을 눌렀을 때만

## 데이터 삭제

- 로컬 데이터: 설정 → 로컬 데이터 전체 삭제
- GitHub 데이터: GitHub repo에서 직접 삭제
- 동의 초기화: 설정 → 동의 초기화

## 민감정보 주의사항

이 앱은 메모 영역에 입력된 텍스트를 그대로 저장합니다.
비밀번호, 금융 정보, 개인식별정보를 메모에 직접 입력하지 마세요.
앱은 민감 패턴을 자동 감지해 마스킹하지만, 완전한 보호를 보장하지 않습니다.

## 오디오 원본

기본적으로 오디오 원본(webm 파일)은 기기 로컬에만 저장됩니다.
설정에서 "오디오 원본 업로드"를 켠 경우에만 GitHub repo에 업로드됩니다.

## 제3자 공유

이 앱은 어떠한 데이터도 제3자에게 전송하지 않습니다.
데이터는 사용자가 직접 설정한 GitHub private repo에만 저장됩니다.
